## 为什么建个人网站

在准备实习和秋招的过程中，我发现一个能集中展示简历、项目和思考的地方非常重要。比起零散地发在各路平台，个人网站能让我完全掌控内容与呈现方式。

## 技术选型

我选择 **Astro** 作为静态站点生成器，原因有几点：

1. **内容优先**：Markdown 写文章非常自然，适合博客场景。
2. **性能好**：默认只输出静态 HTML，首屏加载快。
3. **对非前端友好**：模板语法接近 HTML，不需要深入 React/Vue 生态。

样式方面使用 **Tailwind CSS**，可以快速实现现代、响应式的设计。

## 这次完善

- 为公开项目增加独立详情页，说明问题、技术取舍和当前阶段，并链接到实际源码。
- 统一首页、经历页与文章页的排版，补齐移动导航、深浅主题、项目筛选与文章搜索。
- 为 GitHub Pages 配置 `/personal-site/` 路径，让导航、脚本和样式都能从子目录访问。
- 在构建后检查生成页面的链接和资源，再由 GitHub Actions 发布。

内容维护分成两部分：个人资料和项目使用结构化数据，文章使用 Markdown。这样更新经历时不用反复修改页面模板，也能把私人材料与公开内容分开。
